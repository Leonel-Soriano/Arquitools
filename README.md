# Arquitools — listo para GitHub Pages

1. Sube TODO el contenido de esta carpeta a la raíz de tu repositorio, conservando las subcarpetas. Reemplaza las versiones anteriores. No subas el ZIP sin extraer ni una carpeta contenedora: index.html debe aparecer al abrir el repositorio.
2. Incluye el archivo .nojekyll (puede estar oculto en tu explorador).
3. En Settings → Pages, selecciona Deploy from a branch, la rama donde subiste los archivos (normalmente main) y /(root). Guarda.
4. Espera a que GitHub complete la publicación y abre la URL que aparece en Pages. Si ves una versión antigua, recarga con Ctrl+F5.

No requiere instalar paquetes ni compilar. Funciona tanto en usuario.github.io/repositorio/ como en la raíz de un dominio. No hace falta cambiar el código según el nombre del repositorio.

Los enlaces a hojas de estilo, scripts, imágenes, categorías y simuladores se adaptan a la carpeta de publicación. No cambies las rutas por otras que comiencen por / sin tener en cuenta esa carpeta.

Contiene la oficina, fabricación de maquetas e impresión 3D, las seis herramientas arquitectónicas y los dos simuladores. No incluye credenciales ni configuración de Sites. Los cálculos y simuladores se ejecutan en el navegador; el correo abre Gmail o la aplicación de correo del visitante.

Esta copia es independiente de la versión preparada para Sites. No publiques accidentalmente una versión anterior del ZIP.

Documentación: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
